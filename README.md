# Hangman Game

## Project Overview

The Hangman Game is a simple, text-based word-guessing game developed using Python as part of the CodeAlpha Python Programming Internship.

The program randomly selects a word from a predefined list of five words. The player must guess the hidden word one letter at a time, with a maximum of six incorrect guesses allowed.

## Features

- Random selection of a word from five predefined words.
- Letter-by-letter word guessing.
- Display of correctly guessed letters and remaining incorrect guesses.
- Detection of repeated guesses.
- Win and game-over messages.
- Console-based user interaction.

## Technologies Used

- Python
- Random module
- Lists and strings
- While loops
- Conditional statements
- User input and output

## Installation and Execution

1. Install Python on your computer.
2. Save the source code as `internship-task-1.py`.
3. Open a terminal in the project directory.
4. Run the following command:

   ```bash
   python internship-task-1.py
   ```

5. Enter one letter at a time when prompted.

## How to Play

1. Run the program to start the game.
2. A hidden word will be selected randomly.
3. Enter a letter to guess the word.
4. Correct guesses reveal the matching letters.
5. Incorrect guesses increase the incorrect-guess count.
6. Guess the complete word before reaching six incorrect guesses to win.
